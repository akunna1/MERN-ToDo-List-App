#  Girly-Themed To-Do List App (MERN Stack) 🩷

## 📝 About

This is a **mobile-responsive**, full-stack **To-Do List app** built with the **MERN stack**: MongoDB, Express.js, React.js, and Node.js. With a **girly aesthetic** and intuitive layout, users can create, read, update, and delete their daily tasks with ease.

🌐 **Live Demo:** [akunnatechstudio.com/web](https://akunnatechstudio.com/web)

🗂️ **Branches:** 3 available

---

## ✨ Features

* Girly and visually appealing user interface
* **CRUD functionality** (Create, Read, Update, Delete)
* **Mobile responsive** with Tailwind CSS
* Smooth animations and interactive design using **React Icons**
* Connected to **MongoDB Compass** for local data management

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS, React Icons, Axios
* **Backend:** Node.js, Express.js, CORS, Mongoose, Nodemon
* **Database:** MongoDB (via MongoDB Compass)

## 🚀 How to Run Locally

1. **Clone the repository and navigate into it**

   ```bash
   git clone <repo-url>
   cd <project-folder>
   ```

2. **Install dependencies in both frontend and backend**

   ```bash
   npm install  # Do this in both client and server folders
   ```

3. **Set up your MongoDB connection**

   * Make sure MongoDB is installed and running
   * Add your connection string in `server/.env` or directly in the code (for development)

4. **Run the backend server**

   ```bash
   nodemon server.js
   ```

5. **Run the frontend**

   ```bash
   npm start
   ```

6. **Open the app**

   ```
   http://localhost:3000
   ```
